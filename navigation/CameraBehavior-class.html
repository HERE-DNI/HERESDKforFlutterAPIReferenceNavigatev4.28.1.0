cameraTransitionMode ↔ CameraTransitionMode
Defines how the camera starts following the current position when this camera behavior becomes active. Use CameraTransitionMode.instant to skip the camera animation, for example when returning from a route overview to guidance. The default value is CameraTransitionMode.animated. Gets the currently set camera transition mode.

The normalized principal point. Normalized principal point to be used during navigation. Defaults to (0.5, 0.775), which means the camera will use the position slightly at the bottom of the mapview. Gets the currently set normalized principal point to be used during navigation.

viewRectangle ↔ Rectangle2D?
The view rectangle for camera updates. Defines a sub-space of the screen that the behavior should consider for camera updates. Using a view rectangle keeps the camera positioning consistent across different screen types and orientations without per-screen principal point adjustments. Defaults to null. If not set, it uses the viewport bounds of the underlying map view. Gets the current view rectangle, if it's set.
